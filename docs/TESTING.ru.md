# Тесты

Тесты написаны на Vitest и Testing Library, окружение — jsdom.

```bash
npm test               # один прогон
npm run test:watch     # режим наблюдения
npm run test:coverage  # отчёт покрытия в coverage/
```

Общая обёртка `src/test/renderWithProviders.jsx` оборачивает компонент во все провайдеры:
Redux, TanStack Query, i18next, тему, уведомления и маршрутизатор.

## Что проверяется

| Файл | Проверки |
| --- | --- |
| `src/components/ui/Button.test.jsx` | отрисовка подписи, вызов `onClick`, блокировка во время загрузки |
| `src/components/books/BookCard.test.jsx` | вывод названия, автора и цены; добавление книги в корзину; перевод метки формата |
| `src/components/reviews/ReviewList.test.jsx` | количество пунктов списка, текст на активном языке, сообщение о пустом списке |
| `src/core/models/Order.test.js` | расчёт сумм, разрешённые и запрещённые переходы статусов, отображаемое имя заказа |
| `src/store/selectors.test.js` | поиск, фильтр по формату, сортировка по цене, подсчёт книг по жанрам, итоги корзины |
| `src/services/aboutMeService.test.js` | успешный запрос к API и ошибка при статусе 500 |
| `src/i18n/i18n.test.jsx` | русские и английские тексты, переключение языка из настроек |
| `src/hooks/useDebounce.test.jsx` | значение по умолчанию и обновление после задержки |

Всего 8 файлов и 25 тестов: рендер компонентов, тексты и переводы, изменение состояния,
бизнес-логика моделей и обработка ответа API.

## Скриншот для отчёта

Запустите `npm test` и сделайте снимок экрана с итоговой строкой
`Test Files 8 passed (8)` / `Tests 25 passed (25)`.
