# Соответствие заданиям

| Требование | Где выполнено |
| --- | --- |
| Списки: отдельный функциональный компонент пункта и отдельный компонент списка с `data.map` | `NavList/NavItem`, `CategoryList/CategoryListItem`, `BookGrid/BookCard`, `CartList/CartItemRow`, `ReviewList/ReviewItem`, `OrderList/OrderCard`, `StatList/StatCard`, `FavoriteList/FavoriteCard`, `FactList/FactItem` |
| Модальный диалог из библиотеки (Headless UI) минимум в двух местах | `ui/Modal.jsx` на `@headlessui/react`; используется в карточке книги (отрывок), в админке (форма книги и подтверждение удаления) и в корзине (подтверждение очистки) — четыре места. Меню языка — компонент `Menu` той же библиотеки |
| Все ключи и базовые URL в `.env` с префиксом `VITE_`, чтение через `import.meta.env`, `.env` в `.gitignore` | `.env`, `.env.example`, `src/config/env.js`, строка `.env` в `.gitignore` |
| Проект Node.js с эндпоинтом, отдающим JSON с 10+ фактами о себе, деплой на Vercel | `api/about_me.js` (20 полей), страница `/about-me` показывает ответ, инструкция в `docs/DEPLOY.ru.md` |
| Маршрутизация: минимум три маршрута, вложенные маршруты, страница товара, страница 404 | `src/App.jsx`: разделы `/account` и `/admin` с вложенными маршрутами, `/book/:id`, `/products/:id`, `*` → 404 |
| Асинхронная форма в стиле React с `useActionState` | `components/admin/AsyncBookForm.jsx`, страница `/admin/quick-add` |
| Валидация формы через React Hook Form (и вариант на Formik) | RHF + Zod во всех формах; вариант на Formik + Yup — `components/admin/FormikBookForm.jsx`, страница `/admin/formik` |
| Приложение о любимых книгах: 3+ функциональных компонента, состояние и пропсы, 10 рецензий | Раздел `/favorites`: `FavoriteList`, `FavoriteCard`, `ReviewList`, `ReviewItem`, `ReviewForm`; у первой книги 10 отзывов, новые добавляются в состояние |
| Минимум 5 тестов в отдельном файле | 8 файлов, 25 тестов — см. `docs/TESTING.ru.md` |
| Новые технологии от себя | React 19 (`useActionState`), TanStack Query, Headless UI, i18next (русский и английский интерфейс), Zod, Vitest |
| Сохранение данных | localStorage (корзина, фильтры, отзывы, просмотренные книги) и cookie (сессия, тема, язык) |

## Что показать на защите

1. Каталог: категории слева, фильтры, сортировка, пагинация.
2. Карточка книги: диалог с отрывком, отзывы, добавление отзыва.
3. Корзина: промокод, подтверждение очистки в диалоге, оформление заказа.
4. Личный кабинет: профиль с валидацией, заказы, настройки темы и языка.
5. Админка: статистика, CRUD книг, смена статусов заказов, две формы создания книги.
6. Страница «Обо мне»: данные приходят с эндпоинта, видно тело ответа.
7. Переключение языка RU ↔ EN в шапке.
8. Терминал: `npm test` — 25 тестов проходят.
